# Printer Tuning and Troubleshooting

Printer tuning is easiest when you change one variable at a time and keep notes. Start with basic mechanical and configuration checks before chasing slicer settings.

## Start Here

- [Ellis' Print Tuning Guide](https://ellis3dp.com/Print-Tuning-Guide/) — thorough printer calibration, troubleshooting, and macro guidance
- [Teaching Tech Calibration Guide](https://teachingtechyt.github.io/calibration.html) — PID tuning, e-steps, flow, temperature, and speed
- [OrcaSlicer Calibration](https://github.com/SoftFever/OrcaSlicer/wiki/Calibration) — built-in calibration prints for tuning a printer and filament profile
- [Voron Initial Startup Checks](https://docs.vorondesign.com/build/startup/#initial-startup-checks) — startup checks and configuration guidance that is useful beyond Voron builds

## Klipper-Specific Calibration

- [Configuration Checks](https://www.klipper3d.org/Config_checks.html) — verify motors, heaters, endstops, and basic motion
- [Bed Leveling](https://www.klipper3d.org/Bed_Level.html)
- [Pressure Advance](https://www.klipper3d.org/Pressure_Advance.html)
- [Resonance Compensation](https://www.klipper3d.org/Resonance_Compensation.html) — commonly used to reduce ringing or ghosting

## Diagnosing Print Quality

- [Simplify3D Print Quality Guide](https://www.simplify3d.com/resources/print-quality-troubleshooting/) — visual examples of common print defects and possible fixes
- [3D-Printing Terminology](https://all3dp.com/2/3d-printing-terminology-3d-printing-terms/) — useful vocabulary for describing a problem accurately
- [How to Ask for Help](socials.md) — the information that makes remote troubleshooting much easier

> **Tip:** Save a known-good configuration before major tuning changes. A printer can become impressively mysterious when five settings change at once.
