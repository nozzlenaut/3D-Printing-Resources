# Printer Modifications

These projects range from simple convenience upgrades to major mechanical conversions. Confirm compatibility with your exact printer revision before ordering parts or printing an entire bucket of ABS.

## Chamber Filters

- [BentoBox](https://www.printables.com/model/272525-bentobox-v20-carbon-filter-for-bambu-lab-x1c-enclo) — compact recirculating carbon filter
- [Nevermore](https://github.com/nevermore3d) — open-source recirculating filtration projects

## Voron Community Mods

- [VoronUsers Printer Mods](https://github.com/VoronDesign/VoronUsers/tree/main/printer_mods#readme) — a large collection of modifications in many sizes and styles; some can be adapted to other printers

## Tap-Style Probes

- [Chaoticlab CNC Tap for Voron](https://github.com/Chaoticlab/CNC-Tap-for-Voron) — bill of materials, manual, and STL files
- [Voron Tap](https://github.com/VoronDesign/Voron-Tap/tree/main) — bill of materials, [assembly manual](https://github.com/VoronDesign/Voron-Tap/blob/main/Manual/Assembly_Manual_Tap.pdf), STL files, and configuration examples

## CNC and Carbon-Fiber Parts

- [Chaotic Lab Carbon-Fiber Voron 2.4](https://github.com/Chaoticlab/Carbon-Fiber-Voron2.4)
- [Chaotic Lab Voron 2.4 CNC Parts Kit](https://github.com/Chaoticlab/Voron2.4-CNC-Parts-Kit)

## IDEX and Multi-Material Systems

- [RatRig IDEX](https://lab.ratrig.com/vc31_idex/) — multiple toolheads for separate materials
- [Enraged Rabbit Carrot Feeder](https://github.com/EtteGit/EnragedRabbitProject) — multi-material system for a single toolhead
- FrankenVoron [IDEX](https://github.com/FrankenVoron/IDEX) and [Tridex](https://github.com/FrankenVoron/Tridex)
- [Pico MMU](https://github.com/lhndo/LH-Stinger/wiki/Pico-MMU) — supports up to four filament lanes
- [TradRack](https://github.com/Annex-Engineering/TradRack) — configurable lane count based on build size
- [Happy Hare](https://github.com/moggieuk/Happy-Hare) — filament-management software for multi-material units
- [BoxTurtle](https://github.com/ArmoredTurtle/BoxTurtle/blob/main/README.md)
- [BMCU](https://wiki.yuekai.fr/BMCU) — AMS alternative for Bambu Lab A- and P-Series printers  
  *Compatibility note dated October 1, 2025: X-Series support was reported as nonfunctional.*
- [NightOwl](https://github.com/mjonuschat/NightOwl) — dual-filament changing system

## LEDs

- [Klipper LED Configuration](https://www.klipper3d.org/Config_Reference.html#leds)
- [Klipper LED Effect](https://github.com/julianschill/klipper-led_effect/tree/master)
- [WLED](https://kno.wled.ge/) with [Moonraker](https://moonraker.readthedocs.io/en/latest/configuration/#wled)
- [WLED with Klipper tutorial](https://github.com/nozzlenaut/3D-Printing-Resources/blob/main/misc%20pages/WLED.md)

## Alternative Displays

- [CYD Klipper](https://github.com/suchmememanyskill/CYD-Klipper) — ESP32-based display using Moonraker
- [KlipperScreen on Android](https://klipperscreen.readthedocs.io/en/latest/Android/) — reuse an old phone or tablet
- [Mobileraker](https://mobileraker.com/0) — use a phone as a Klipper interface
- Use [Fluidd](https://fluidd.xyz/) or [Mainsail](https://mainsail.xyz/) from any device with a web browser; add a mount for a dedicated local display or connect remotely
